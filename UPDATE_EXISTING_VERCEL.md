# Update your existing Vercel MessCal project

This ZIP is an update to the existing `messcal` project. Do not create a new Vercel project.

1. Copy these files over your current MessCal project (keep your existing `.env` locally).
2. From the project root, run `vercel link` and choose the existing `messcal` project if the folder is not already linked.
3. Run `vercel --prod`.
4. Confirm the deployment is aliased to `https://messcal.vercel.app`.

The new Manage MessCal section appears near the bottom of the page after the Export area.
